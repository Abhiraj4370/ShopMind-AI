# \# ShopMind AI

# 

# A location-aware web application featuring dynamic regional merchant routing, product sorting, and multi-LLM backend integration to revolutionize the e-commerce and decision-making experience.

# 

# \## 🚀 Features

# \* \*\*Multi-Agent AI Architecture:\*\* Powered by LangGraph, utilizing specialized agents for Search, Recommendation, Comparison, and Checkout.

# \* \*\*Regional Intelligence:\*\* Dynamic regional merchant routing, localized pricing, and instant delivery integration (BuyHatke).

# \* \*\*Modern UI/UX:\*\* A fast, responsive, and video-inspired user interface with interactive product cards and comparison tables.

# \* \*\*Mock Merchant Ecosystem:\*\* Built-in simulated catalogs (Megamart, Techzone, Homegoods) for seamless testing and demonstration.

# 

# \## 💻 Tech Stack

# \* \*\*Backend:\*\* Python, LangGraph (Workflow Orchestrator), Multi-LLM Integration, REST APIs.

# \* \*\*Frontend:\*\* React, Vite, Modern CSS.

# \* \*\*Infrastructure:\*\* Docker (Containerization).
